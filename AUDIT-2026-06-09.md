# build-fleet v0.5.0 — Audit Synthesis & Improvement Plan

## 1. Verdict

build-fleet is an unusually well-engineered plugin at the architecture level — correct auto-discovery layout, portable `${CLAUDE_PLUGIN_ROOT}` paths everywhere, a genuinely novel single-writer scribe pattern, schema-validated agent outputs, hermetic test harnesses that all pass, and live-validated workflows — but it is not yet at professional standard for its stated audience. Three things stand between it and that bar: **(1) the enforcement layer is weaker than its marketing** — every published release is legally unadoptable (no license has ever been committed), the "deterministic gates" admit path-traversal, Bash-write, wrong-cwd, missing-jq, and unexpected-error bypasses (most fail *open*), and 6 of 9 gate hooks have no tests and no CI; **(2) the documentation-of-record actively misleads** — sdd-protocol contradicts itself about the shipped classifier, CLAUDE.md describes a v0.1 system that no longer exists, agent descriptions forbid documented entry points, and three commands instruct parsing a field (`estimatedCost`) that exists in no file; **(3) the headless contract the plugin sells to orchestrators is partly fictional** — exit-code tables a slash command cannot honor, an unbounded retry loop in the most expensive workflow, unverified scribe application that has already silently failed in the project's own smoke run, and `UNKNOWN_TIME` stamped across the feature lane's append-only audit trail. All of this is fixable in days, not weeks — the fixes are mostly small, and the repo's own patterns (plan-review.js's cleanupEnvelope, next-feature.sh's deterministic extraction, the existing test harness style) already contain the correct solutions.

## 3. Professional-standard gaps (majors, grouped by theme)

### Theme A — The gate layer is bypassable and fails open

The plugin's core promise is "gates are deterministic, enforced by hooks, not vibes." Five independent holes contradict it, and most fail in the *open* direction.

1. **Path traversal defeats all three write gates.** `/Users/rocconno/build-fleet/hooks/scripts/_lib.sh:119-150` — `path_in_sdd`/`path_in_active_sdd`/`path_in_tests` are pure glob prefix matches. Empirically: `.sdd/../src/app.py` → allowed while `src/app.py` → blocked; same for `tests/../src/app.py` against the inviolable reproducing-test gate. The official hook-development skill lists `..` rejection as baseline. **Fix:** reject any `..` segment first in all three helpers (`case "$p" in *../*|*/..|..) return 1 ;; esac`), add traversal cases to `block-source-before-finalized.test.sh` and `require-reproducing-test.test.sh`.

2. **Bash and NotebookEdit are unguarded escape hatches.** `/Users/rocconno/build-fleet/hooks/hooks.json:6` binds all PreToolUse gates to `"matcher": "Write|Edit"`, and the scripts explicitly allow empty `file_path` ("Tool call without a file_path (e.g. Bash) → allow", block-source-before-finalized.sh:20-21). coder/qa/devops all hold Bash — `cat > src/app.py <<EOF` walks through every gate. **Fix:** add a `Bash`-matcher PreToolUse entry inspecting `.tool_input.command` for write patterns during locked phases (or deny Bash writes outright pre-FINALIZED/pre-CONFIRMED and document the residual risk); extend the matcher to cover NotebookEdit and parse `notebook_path // file_path`.

3. **Wrong cwd silently disables everything.** `/Users/rocconno/build-fleet/hooks/scripts/_lib.sh:17` reads literal `.sdd/ACTIVE`; every gate begins `[ -n "$slug" ] || exit 0`. A drifted/non-root cwd → empty slug → all gates exit 0, indistinguishable from the legitimate no-active-feature path. Zero `CLAUDE_PROJECT_DIR` usage in hooks/. **Fix:** anchor `_lib.sh` with `cd "${CLAUDE_PROJECT_DIR:-$PWD}" || exit 0` and use it in `path_in_*`; add a drifted-cwd test.

4. **Missing jq silently converts all gates to no-ops, and jq is undeclared.** `_lib.sh:8-13` `require_jq` exits 0 with a stderr warning the model never sees (only exit-2 stderr is fed back). README's Requirements section (line 166) never mentions jq — and the new `scripts/status-snapshot.sh:47` hard-requires it too. **Fix:** fail closed (exit 2 with install instructions) or fall back to pure-bash extraction of `tool_input.file_path`; declare jq in README Requirements; consider a SessionStart one-time warning.

5. **Unexpected script errors fail open by architecture** *(cross-cutting, not adversarially verified, but mechanically sound)*. Every gate runs `set -euo pipefail` with no `trap ... ERR`; any runtime error exits 1, which is non-blocking per the hooks contract — the exact failure mode CHANGELOG 0.5.0 admits already shipped once ("letting a source write slip the gate... a latent spec.md bypass dating to v0.2"). **Fix:** `trap 'echo "build-fleet: gate errored — failing closed" >&2; exit 2' ERR` in the blocking PreToolUse gates, keeping deliberate allows as explicit `exit 0`; add a fault-injection meta-test. Relatedly *(also unverified)*: **bash itself is a hard undeclared dependency** — all 9 hook registrations spawn `bash`, and on Windows without Git Bash/WSL the whole backbone silently vanishes. Add a platform line to Requirements.

6. **stop-tests.sh can stall stop sequences with no loop guard or timeout.** `/Users/rocconno/build-fleet/hooks/scripts/stop-tests.sh:44-59` never reads stdin (ignores `stop_hook_active`), `hooks.json:52-63` sets no `timeout`. A persistently-red suite re-blocks up to the platform's 8-block cap at up to 600s per run (~80 min stall), with no ESCALATION.md — violating the plugin's own "bounded at 3, escalate" contract; a suite exceeding 600s is cancelled and the gate silently passes. **Fix:** read stdin and honor the loop guard; maintain a bounded retry counter in `.sdd/<slug>/` that escalates to ESCALATION.md; set explicit `timeout`; document an operator override flag file.

7. **Reviewer write-restriction has an unenforced window, and architect.md lies about it.** `restrict-reviewer-writes.sh` fires only in REVIEW|CHANGE_REVIEW; once FINALIZED, BUILD/HANDOFF are wide open to architect's Edit (`/Users/rocconno/build-fleet/agents/architect.md:4`) and qa's Write/Edit/Bash (`agents/qa.md:4`) — yet architect.md:143-144 claims "The hooks will block you." **Fix:** at minimum correct architect.md/qa.md to state the BUILD/HANDOFF boundary is prompt-enforced only; better, pass reviewer roles with restricted `AgentDefinition.tools` in the BUILD dispatch or key a hook on a phase+role marker file.

8. **6 of 9 gate scripts have no tests, no CI, no test entrypoint, no README instructions.** Only 3 hook suites exist (37 cases); `restrict-reviewer-writes.sh`, `check-review-written.sh`, `stop-tests.sh`, `reap-stale-workflow-markers.sh`, `validate-backlog-status.sh`, and `validate-spec-status.sh` (one incidental case only) are untested. No `.github/`, no Makefile, no run-tests.sh; `grep -i smoke README.md` → nothing. The 0.5.0 fail-open bug sat undetected for three releases. **Fix:** one entrypoint (`scripts/run-tests.sh`) running all `*.test.sh` + `docs/v0.5/smoke/smoke.sh`; GitHub Actions on push/PR with a macOS-bash-3.2 + Linux-bash-5 matrix; tests for the six uncovered hooks (validate-spec-status first); a README "Development / running the tests" section.

### Theme B — The workflow runtime breaks its own contracts

9. **Feature-lane audit trail gets `UNKNOWN_TIME`.** `workflows/review.js:47` falls back to `"UNKNOWN_TIME"` when `args.now` is absent — and `commands/review.md:48`, `commands/deep-build.md:53`, `commands/finalize.md:186` all dispatch without `now` (diagnose.md:82 and plan-review.md:84 do it correctly). Every feature-lane REVIEW.md cycle header, PROGRESS `UPDATED`, and escalation `emitted_at` is literally "UNKNOWN_TIME". **Fix:** add `"now": "<iso8601>"` to the three dispatch specs; make the scripts fail validation when `now` is absent (deep-build.js:45's error message already claims it's required but never checks).

10. **Cost-preview contract drift.** `commands/review.md:38`, `deep-build.md:45`, `finalize.md:179` instruct parsing an `estimatedCost` meta field that exists nowhere; the ceilings live in the `@cost-ceiling` header comment (review.js:12-15 says so explicitly; diagnose.md:74/plan-review.md:76 were already updated). The headless `BUILD_FLEET_COST_PREVIEW` line will be skipped or hallucinated. **Fix:** align the three commands to the `@cost-ceiling` wording.

11. **deep-build has no cycle bound; its escalate branches are dead code.** `workflows/deep-build.js:261` can only yield `needs-iteration|clean`, so `verdict === "escalate"` at lines 396/408/415-416 is unreachable; `needs-iteration` emits `next_legal_commands: ["/build-fleet:deep-build"]` with no budget — an orchestrator mechanically following the envelope retries the 400k-token workflow forever, contradicting "bounded review cycles" and CLAUDE.md hard gate 4. **Fix:** add a `cycle` arg backed by a `BUILD_CYCLE` field in PROGRESS.md (CHANGE_CYCLE already exists), escalate at the budget like review.js:160, delete/wire the dead branches.

12. **applyScribe results are never checked — state application can silently fail behind a success verdict.** `review.js:171`, `deep-build.js:270`, `diagnose.js:160`, `plan-review.js:152` all discard the scribe's return despite scribe.md defining `SCRIBE_OK:`/`SCRIBE_ERROR` tokens — and docs/v0.2/CONTRACT.md records a real run where scribe effects didn't land while the workflow returned `verdict:"clean"`. **Fix:** pass a schema to applyScribe (or check for the `SCRIBE_OK:` prefix), retry once, then surface `scribe-apply-failed` in the workflow's return object.

13. **One transient agent failure bricks the feature.** `review.js:124-131` (also `diagnose.js:107-115`, `deep-build.js:191-198`) converts a `parallel()` null (any error, incl. timeouts) into terminal `PHASE: ESCALATED` + ESCALATION.md, which every command then refuses against — recovery is manual file surgery. `plan-review.js:107-132` already ships the correct pattern (cleanupEnvelope: verdict `incomplete`, PHASE/CYCLE untouched, marker removed, "re-run"). **Fix:** adopt it for missing/null payloads in the other three; reserve ESCALATED for genuine cycle exhaustion (for deep-build, preserve human inspection of partial writes in the message).

14. **Top-level workflow throws orphan `.workflow-in-flight`, disabling two reviewer hooks for up to an hour.** Args-validation throws at `review.js:49-54` (and the other three workflows) fire before any applyScribe; the script can't touch the filesystem; the commands' cleanup obligation covers launch failure only (review.md:36); the reaper requires Stop + >3600s (`reap-stale-workflow-markers.sh:21`). **Fix:** route validation failures through a scribe cleanup envelope; have dispatch commands poll the run (TaskGet) and delete the marker on early failure; lower the reaper threshold; while in there, add run-ownership to the marker (write the runId at dispatch, scribe deletes only its own) so the reaper can't kill a live run's marker.

15. **hello.js is a dev probe shipping in the release.** `/Users/rocconno/build-fleet/workflows/hello.js` — "M0 EMPIRICAL PROBE", hardcoded `/Users/rocconno/build-fleet` path (line 25), self-disclaimed wrong API shape, question marked RESOLVED in docs/v0.2/CONTROLS.md:91, referenced by nothing. README:157 says "Four dynamic workflows" while five .js files ship. **Fix:** delete it (move probe notes to docs/v0.2/), which also fixes the README count.

### Theme D — Command surface safety and honesty

22. **plan-finalize's human-ratification gate is model-invocable.** `commands/plan-finalize.md:1-5` sets no `disable-model-invocation: true` (no command does), so Claude can self-invoke `/build-fleet:plan-finalize ratify force` — directly contradicting the documented "cannot ratify on its own" headless safety story (lines 17-19; README:484-486). **Fix:** add the flag to plan-finalize.md (mandatory); evaluate for handoff.md and ship-fix.md, carefully — those are orchestrator-dispatched in the DEVELOPING loop; if model invocation of the dry-run is wanted, split dry-run and ratify.

23. **handoff.md and status.md are the only commands with no `allowed-tools`.** `commands/handoff.md:1-4` (highest-stakes forward-lane command: runs tests, writes ESCALATION.md, fans out four agents, clears `.sdd/ACTIVE`) and `commands/status.md:1-4` (claims "never writes any file" at line 121, needs Bash for two scripts) inherit whatever the conversation allows. The repo's own analogs prove the intended frontmatter (ship-fix.md, next-feature.md). **Fix:** `allowed-tools: Read, Write, Edit, Bash, Task` on handoff.md; `Read, Bash` scoped to the resolver scripts on status.md.

24. **Published exit-code contracts are unenforceable fiction.** Eight commands (`commands/review.md:69-76`, deep-build.md, diagnose.md, dispatch.md, plan-review.md, plan-finalize.md, next-feature.md, product-memory.md — plus docs/v0.2/CONTRACT.md:610-619) document exit codes a markdown prompt cannot set; headless callers see exit 0 on every refusal, and CONTRACT.md tells Hermes to map exit codes to kanban transitions — it would mark every refusal successful. **Fix:** delete the tables; carry a reason code inside the `BUILD_FLEET_REFUSE` JSON (`{"code":3,"reason":"workflow-runtime-unavailable"}`); state that the signal lines are the sole machine contract. Update CONTRACT.md.

25. **/finalize silently runs the entire BUILD phase.** `commands/finalize.md:98-260` — described as a gate + state flip, but step 6 inlines ~160 lines of build orchestration duplicating deep-build.md's dispatch steps, creating the documented finalize/deep-build confusion and the non-idempotency caveats (lines 259-265). **Fix:** split into `/build-fleet:finalize` (gate only, idempotent) and `/build-fleet:build` (qa→coder + BUILD_MODE routing).

26. **The intent-block grammar is duplicated prose with an in-file admission of the risk.** `commands/next-feature.md:57-66` restates `new-feature.md:58-71` verbatim and concedes "a mismatch would... defeat this gate." The repo already centralizes row parsing in `scripts/next-feature.sh`. **Fix:** extend that script (or add `scripts/intent-block.sh`) to emit the block + usable/too-thin verdict; both commands call it; keep one prose definition of the quality floor in sdd-protocol.

27. **The workflow points humans at commands that don't exist.** `commands/triage.md:31` ("the human parks the feature first" — no park command), `diagnose.md:36-37` ("abandon the bug" — no mechanism), `status.md:59-60` ("only a human unblocks an escalation" — undocumented file surgery). Only a successful handoff/ship-fix ever clears `.sdd/ACTIVE`, so a sev0 against a mid-flight feature requires hand-editing state. **Fix:** add `/build-fleet:park` (empties ACTIVE, records parked state in PROGRESS.md — the sanctioned sev0 preemption path) and `/build-fleet:resolve-escalation` (archives ESCALATION.md into REVIEW.md, resets the cycle counter), with the standard refusal/signal conventions. This also un-bricks Theme-13's escalations cleanly.

28. **verify.md delegates destructive working-tree mutation with no snapshot.** `commands/verify.md:29-33` has qa `git stash`/checkout the *uncommitted, only copy* of the fix with no precondition, no restore verification, no recovery path (the checkout variant is outright destructive; qa.md:125-128 and sdd-protocol:554-556 repeat the pattern). **Fix:** record a `git stash create` SHA (or temp-branch commit) in IMPL_NOTES.md before the counterfactual; qa operates against that ref; orchestrator verifies `git status`/diff matches pre-counterfactual state before evaluating the verdict.

29. **product-memory's "never clobber" guarantee on the user's root CLAUDE.md is untested LLM-executed prose** *(cross-cutting, not adversarially verified)*. `commands/product-memory.md:59-70,79-80` — a marker-splice via model-driven Edits on the most sensitive user-owned file, with zero test fixtures, unlike every other deterministic piece of the repo. **Fix:** move the splice into `scripts/product-memory-splice.sh` (block on stdin) with a harness covering no-file / block-present / block-absent / missing-END / duplicate-final-line.
